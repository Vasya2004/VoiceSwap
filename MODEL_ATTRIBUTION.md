# Speech Model Attribution

The `SuperDictate-Model-v3.zip` release asset contains the Core ML files used
by SuperDictate for local speech recognition.

- Original model: [NVIDIA Parakeet TDT 0.6B v3](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3)
- Core ML conversion: [FluidInference/parakeet-tdt-0.6b-v3-coreml](https://huggingface.co/FluidInference/parakeet-tdt-0.6b-v3-coreml)
- Pinned upstream revision: `aed02740059203c4a87495924f685de3722ae9ce`
- License: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)

SuperDictate redistributes only the runtime Core ML subset required by the
application. The model files themselves are unmodified.
