# VoiceSwap

VoiceSwap — локальная диктовка для Mac: говорите, а приложение превращает речь в текст прямо в активном поле. Распознавание выполняется на устройстве, без отправки аудио в облако.

Требуется Mac с Apple Silicon (M1 или новее) и macOS 14 или новее.

## Установка

Вставьте команду в Терминал:

```bash
curl -fsSL https://raw.githubusercontent.com/Vasya2004/VoiceSwap/main/install-voiceswap.sh | bash
```

Установщик проверяет SHA-256 скачанного релиза, обновляет существующую копию `VoiceSwap.app`; при новой установке использует `~/Applications` и открывает его. При первом запуске macOS попросит разрешения на микрофон, универсальный доступ и мониторинг ввода. Поскольку релизы пока подписаны ad-hoc, если macOS заблокирует первый запуск, откройте приложение через контекстное меню Finder → **Открыть**.

## Горячие клавиши

По умолчанию:

- Правый Command — начать диктовку.
- Правый Command ещё раз — закончить, распознать и вставить текст.
- После первого Правого Command нажмите Правый Option — закончить, распознать, вставить текст и сразу отправить его клавишей Return.

Режим с двумя нажатиями Right Command остаётся обычной диктовкой: он не отправляет сообщение автоматически.

## Сборка из исходников

```bash
git clone https://github.com/Vasya2004/VoiceSwap.git
cd VoiceSwap
swift run -c debug --package-path swift Parakey --self-test all
SIGN_IDENTITY=- ./scripts/build-app.sh ./dist/VoiceSwap.app
./scripts/install-local.sh
```

## Конфиденциальность

Основная транскрибация работает локально. При первом запуске загружается модель распознавания речи. Функции AI-обработки текста, если их включить в настройках, могут обращаться к выбранному пользователем провайдеру — это отдельная опция.

## Локальная разработка и проверки

```bash
swift run --package-path swift VoiceSwapCoreChecks
bash scripts/check.sh
bash scripts/test-install.sh
# Интеграционные проверки — отдельный явный запуск:
swift run -c debug --package-path swift Parakey --self-test all
```

При наличии Xcode: `swift test --package-path swift` запускает те же чистые проверки
через XCTest. Для Command Line Tools используйте `VoiceSwapCoreChecks`.

Локальная установка: `scripts/install-local.sh`. Существующий сертификат подписи
сохраняется; другой настроенный сертификат задаётся через `VOICESWAP_SIGN_IDENTITY`.
При отсутствии сертификата используется ad-hoc: после пересборки macOS может снова
попросить разрешения. Сброс разрешений автоматически не выполняется.

× и Escape удаляют текущую запись без распознавания. При смене поля или невозможности
подтвердить вставку результат показывается отдельно с кнопкой копирования. Если
вставка не подтверждена, проверьте поле перед ручным копированием: повторная вставка
автоматически не выполняется. Return отправляется только после подтверждения
вставки и повторной проверки исходного поля.

## Удаление

`./uninstall.sh` удаляет приложение и автозапуск, сохраняя данные.
`./uninstall.sh --purge-data` дополнительно удаляет настройки, историю, временное аудио,
кеш и журналы приложения. Оба режима сохраняют исходники, резервные копии,
Keychain-запись и общие модели FluidAudio. Путь можно задать через `VOICESWAP_APP_PATH`.

## Подготовка выпуска

`scripts/prepare-release.sh <VoiceSwap.app> <каталог>` создаёт архив, SHA-256,
`update.json` и тег из версии в Info.plist. Эта команда ничего не публикует.
Workflow выпуска не перезаписывает существующий релиз и публикует согласованные
артефакты только после проверок. Для нового выпуска увеличьте версию в Info.plist
и установщике одновременно.
