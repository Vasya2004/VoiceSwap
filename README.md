# VoiceSwap

VoiceSwap — локальная диктовка для Mac: говорите, а приложение превращает речь в текст прямо в активном поле. Распознавание выполняется на устройстве, без отправки аудио в облако.

Требуется Mac с Apple Silicon (M1 или новее) и macOS 14 или новее.

## Установка

Вставьте команду в Терминал:

```bash
curl -fsSL https://raw.githubusercontent.com/Vasya2004/VoiceSwap/main/install-voiceswap.sh | bash
```

Установщик проверяет SHA-256 скачанного релиза, помещает `VoiceSwap.app` в `/Applications` и открывает его. При первом запуске macOS попросит разрешения на микрофон, универсальный доступ и мониторинг ввода. Поскольку релизы пока подписаны ad-hoc, если macOS заблокирует первый запуск, откройте приложение через контекстное меню Finder → **Открыть**.

## Горячие клавиши

По умолчанию:

- Правый Command — начать диктовку.
- Правый Command ещё раз — закончить, распознать и вставить текст.
- После первого Правого Command нажмите Правый Option — закончить, распознать, вставить текст и сразу отправить его клавишей Return.

Режим с двумя нажатиями Right Command остаётся обычной диктовкой: он не отправляет сообщение автоматически.

## Сборка из исходников

```bash
git clone https://github.com/Vasya2004/VoiceSwap.git
cd VoiceSwap
swift run -c debug --package-path swift Parakey --self-test all
SIGN_IDENTITY=- ./scripts/build-app.sh ./dist/VoiceSwap.app
open ./dist/VoiceSwap.app
```

## Конфиденциальность

Основная транскрибация работает локально. При первом запуске загружается модель распознавания речи. Функции AI-обработки текста, если их включить в настройках, могут обращаться к выбранному пользователем провайдеру — это отдельная опция.
